4 MOMENTS PAGE LOAD REAL DATA
================================================

Instead of static cards, load vows from Supabase.

Table:

orders

Fields:

sender_name
receiver_name
message
created_at

Query example:

supabase
.from("orders")
.select("sender_name,receiver_name,message,created_at")
.order("created_at",{ascending:false})
.limit(6)
